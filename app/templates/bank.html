API endpoints

MethodPath
GET/api/bank/products
POST/api/bank/offers {business_id, product_id}
POST/api/bank/offers/{id}/approve
POST/api/bank/offers/{id}/reject
POST/api/bank/offers/{id}/disburse (Idempotency-Key header)
POST/api/bank/repayments/{id}/pay
GET/api/bank/loans?business_id=

Duplicate disburse attempts return 409 duplicate_action. Execution without the owner's single-use approval token returns 409 approval_missing; a token for different terms returns 409 approval_terms_changed. Open API docs: /api/docs

Example flow

curl -X POST localhost:8000/api/bank/offers \
  -H "Content-Type: application/json" \
  -d '{"business_id": 3, "product_id": "receivable_bridge"}'

# every call needs the owner's session cookie (cb_session) and X-CSRF-Token
curl -X POST localhost:8000/api/bank/offers/1/approve \
  -H "Content-Type: application/json" -d '{}'
# -> {"approval_token": "...", "expires_in_seconds": 300}

curl -X POST localhost:8000/api/bank/offers/1/disburse \
  -H "Idempotency-Key: demo-disburse-1" -H "X-Approval-Token: "
